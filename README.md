# Harmony Music (React + Capacitor Android)

An open-source Android music player application inspired by Harmony-Music and YouTube Music, built with React, Tailwind CSS, and Capacitor.

## Automated APK Build (GitHub Actions)

This repository includes a pre-configured GitHub Actions workflow (`.github/workflows/build-apk.yml`).

### How to get the APK:
1. Push this repository to GitHub on `main` or `master`.
2. Go to the **Actions** tab in your repository.
3. The **Generate Android APK** workflow will automatically run.
4. Once completed (approx. 3-4 minutes), scroll down to **Artifacts** and download `HarmonyMusic-debug-apk`.
5. Install the extracted `app-debug.apk` directly on your Android phone!
